# First Server & Database Connection

## 📌 Project Description
This project is the first step in learning backend development with Node.js, Express, and MongoDB. It creates a basic Express server and connects it to a MongoDB database using Mongoose.

## 🚀 Features
- Express server setup
- MongoDB connection with Mongoose
- Environment variables using dotenv
- Basic project structure
- Server startup confirmation
- Database connection status

## 🛠️ Technologies Used
- Node.js
- Express.js
- MongoDB
- Mongoose
- Dotenv
- Nodemon

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/your-repository.git
```

2. Navigate to the project folder

```bash
cd your-repository
```

3. Install dependencies

```bash
npm install
```

4. Create a `.env` file

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
```

5. Start the server

```bash
npm run dev
```

or

```bash
npm start
```
